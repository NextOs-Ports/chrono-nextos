CHRONO TRIGGER — NextOS Ports (BYO data / dados por sua conta)
===============================================================

PT-BR
-----
Este pacote NAO contem nenhum dado do jogo. Nenhum APK, nenhum asset e
nenhuma biblioteca da Square Enix acompanha o download — apenas o codigo
aberto do port.

Para jogar, copie para ESTA pasta o APK do Chrono Trigger que voce comprou
legalmente na Google Play (arm64 / arm64-v8a) e abra o port pelo menu.
O instalador reconhece o pacote pelo CONTEUDO, entao o nome do arquivo nao
importa: pode ser .apk, .apkm, .apks, .xapk ou .zip.

Na primeira abertura o instalador extrai, valida e publica os dados; nas
aberturas seguintes ele so' confere o marcador e vai direto para o jogo.
O seu APK NUNCA e' apagado.

Se aparecer "nenhum conjunto de entrada casa com esta receita", o arquivo
provavelmente e' de OUTRA build/versao do jogo (ou de outro jogo). Os detalhes
ficam em nxextract.log, dentro da pasta chrono.

EN
--
This package contains NO game data: no APK, no assets and no Square Enix
libraries ship with the download — only the port's own source code.

To play, copy the Chrono Trigger APK you legally own (arm64 / arm64-v8a) into
THIS folder and launch the port from the menu. The installer identifies the
package by CONTENT, so the file name does not matter: .apk, .apkm, .apks,
.xapk or .zip all work.

The first launch extracts, validates and publishes the data; later launches
only check the marker. Your APK is never deleted.

If you see "no input set matches this recipe", the file is most likely a
different build/version of the game (or a different game). Details land in
nxextract.log inside the chrono directory.
